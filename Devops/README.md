# End-to-End DevOps Project on AWS

AWS | Terraform | Docker | Kubernetes | DevOps Automation

## 📌 Project Overview

This project demonstrates hands-on implementation of DevOps practices using AWS cloud services and modern DevOps tools. It focuses on infrastructure provisioning, containerization, Docker image management, and Kubernetes cluster creation.

The project covers provisioning AWS infrastructure using Terraform, building and managing Docker images, pushing container images to Docker Hub, and exploring Kubernetes cluster management using Amazon EKS.

The primary objective is to gain practical experience in cloud infrastructure management, containerization, and DevOps workflows.

## ⚙️ Project Implementation

### 1. AWS Infrastructure Provisioning using Terraform

- Worked on AWS infrastructure provisioning using Terraform.
- Created infrastructure configurations using Terraform files.
- Worked with VPC and subnet configuration.
- Configured S3 bucket resources.
- Practiced Terraform initialization, planning, and applying infrastructure changes.
- Explored AWS infrastructure architecture.

**Terraform files:**
- `main.tf`
- `s3.tf`
- `subnet.tf`
- `vpc.tf`

### 2. Docker Containerization

- Worked on Docker installation and configuration.
- Built Docker images for an application.
- Applied image tagging to Docker images.
- Created Docker Hub access credentials.
- Pushed Docker images to Docker Hub.
- Verified image availability in the Docker Hub repository.

### 3. Kubernetes & Amazon EKS

- Explored Kubernetes container orchestration.
- Created an Amazon EKS cluster.
- Practiced basic Kubernetes cluster management.

- Worked with application-related files.
- Explored JavaScript application structure.
